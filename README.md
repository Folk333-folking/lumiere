# LUMIÈRE

Сайт студии маникюра: главная, услуги, мастера, галерея, онлайн-запись и кабинет.

Записи, сертификаты, отзывы и избранное хранятся в браузере. Отдельная база не нужна.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://localhost:8080](http://localhost:8080).

## Кабинет

Страница `/admin`, демо-пароль `lumiere`.

Промокоды: `LUMIERE10` (минус 10%) и `QUIET500` (минус 500 ₽ по вторникам). Сертификат для проверки: `GIFT-4401`.

## Сборка

```bash
npm run build
```
